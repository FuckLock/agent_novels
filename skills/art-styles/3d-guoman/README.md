# 3D 国漫风格说明

本风格专为"3D 国漫"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **3D 国漫世界观**：以中国古风为背景，对标《完美世界》《斗破苍穹》《斗罗大陆》等头部国漫3D动画的视觉质感。
- **核心渲染特征**：UE5 级别实时渲染画质、PBR（物理渲染）材质体系、体积光（Volumetric Lighting）营造氛围纵深、景深突出主体。
- **东方美学构图**：留白、对称、层叠远山、云雾缭绕，强调诗意与意境。
- **情感表达**：适用于仙侠、玄幻、武侠等题材。

## 适用范围

- 3D 国漫题材的 AI 美术生成（角色、场景、道具、分镜等）
- 需要 UE5 级实时渲染质感与东方美学构图的视觉创作
