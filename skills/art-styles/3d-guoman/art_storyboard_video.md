# 视频提示词风格模板（3D 国风）

本模板用于 Seedance 视频生成阶段，规范每条视频提示词的风格表达、画质要求和反向约束。

---

## 1. 风格锚点词

每条视频提示词**必须**包含以下锚点词（可微调语序，不可删减核心概念）：

```
国风3D渲染，PBR材质，体积光，东方美学，典雅大气，电影风格
```

使用说明：
- 锚点词放在提示词段落的**开头或前半段**，确保风格权重最高
- 可在锚点词之间插入场景/人物描述，但六个核心概念缺一不可
- 示例：`国风3D渲染，一位身着青色长衫的少年立于庭院中，PBR材质质感的石桌上放着棋盘，体积光从月门洒入，东方美学构图，典雅大气的色彩氛围，电影风格的景深效果`

---

## 2. 画质锁定词

每条提示词末尾追加画质锁定词，确保生成质量稳定：

```
best quality, masterpiece, 8k, cinematic lighting, film grain
```

中文等价版本（二选一，视平台支持情况）：

```
最高画质，杰作级别，8K分辨率，电影级光照，胶片质感
```

---

## 3. 反向提示词模板

所有视频生成任务统一使用以下反向提示词（Negative Prompt）：

```
low quality, blurry, deformed, extra limbs, watermark, text, nsfw, realistic photo, western style
```

补充说明：
- `realistic photo`：防止风格滑向写实摄影，保持 3D 国风渲染质感
- `western style`：防止建筑、服饰、道具出现西式元素
- 如场景涉及文字道具（如匾额、书信），可临时移除 `text`，但须在备注中说明

---

## 4. 情绪面部映射

视频提示词中涉及人物特写和近景时，**必须引用**情绪面部映射规范：

> 参考文件：`.claude/skills/seedance-storyboard-skill/emotion_face_mapping.md`

该文件定义了 **9 种核心情绪**的面部/眼部描写规范：

| 情绪 | 面部要点 | 视频提示词中的应用 |
|------|----------|-------------------|
| 愤怒 | 眉头紧锁、颌骨绷紧、瞳孔收缩 | 描述角色面部时直接引用对应的面部特征词 |
| 悲伤 | 眉尾下垂、眼眶含泪、嘴角微颤 | 结合体积光的暗调渲染增强情绪感 |
| 喜悦 | 眉眼弯弯、颧骨微隆、唇角上扬 | 搭配暖光和亮色调 |
| 恐惧 | 瞳孔放大、面色苍白、肌肉僵硬 | 搭配冷色调和阴影 |
| 惊讶 | 双眉上挑、嘴唇微张、眼睛圆睁 | 用短暂定格强调瞬间表情 |
| 厌恶 | 鼻翼皱起、上唇微抬、眉心微蹙 | 描述时注意克制，保持古风含蓄感 |
| 轻蔑 | 嘴角单侧上扬、眼神微垂、下巴微抬 | 搭配冷光侧照 |
| 温柔 | 眉眼舒展、目光柔和、唇角含笑 | 搭配柔光和浅景深 |
| 隐忍 | 咬肌微动、目光坚定、双唇紧抿 | 搭配暗调和侧逆光 |

**规则**：
- 近景及以上景别（特写、近景）必须明确描述面部情绪特征
- 中景可简要提及，远景和全景可省略
- 面部描写融入叙事段落，不单独列为标签

## 5. 与柔化词系统的关系

本模板与柔化词系统（Softening System）**互补不冲突**，各司其职：

| 系统 | 作用层面 | 目标 |
|------|----------|------|
| **柔化词系统** | 文本描述层 | 替换负面/暴力/恐怖描述词，使提示词通过平台审核 |
| **反向提示词** | 图像生成层 | 在生成端排除低质量、风格偏移等技术性问题 |

协作方式：
- 先由柔化词系统处理文本内容，确保描述合规
- 再附加反向提示词，确保生成画面质量达标
- 两者同时生效，不互相替代

## 6. 视频特有约束

### 6.1 首帧原则——动作描述

视频生成以首帧为起点，因此动作描述必须使用**准备姿态**，而非动作顶点：

| 错误写法 | 正确写法 |
|----------|----------|
| 他飞身跃起，剑刺向对手 | 他双膝微屈蓄力，长剑斜指前方，即将跃起 |
| 她猛然转身甩袖离去 | 她侧身站立，衣袖微扬，目光投向身后 |
| 拳头重重砸在桌上 | 他抬起右拳悬于桌面上方，怒目圆睁 |

### 6.2 运镜融入叙事

运镜描述必须**融入叙事段落**，不单独标注为技术参数：

| 错误写法 | 正确写法 |
|----------|----------|
| 镜头：缓慢推近。角色表情悲伤。 | 视线逐渐靠近她的面庞，泪痕在体积光下隐约可见 |
| Camera: dolly in. 她低头不语。 | 她低垂的眉眼渐渐占据整个画面，细碎的睫毛微微颤动 |

### 6.3 连续叙事段落

每条提示词必须是**一段连贯的叙事文字**，禁止使用结构化标签格式：

| 禁止格式 | 要求格式 |
|----------|----------|
| 【场景】庭院 【人物】少年 【动作】站立 【光线】侧光 | 国风3D渲染，庭院中一位少年静立于石阶前，PBR材质的青石地面映着侧方透入的体积光，他身着月白长衫，目光平静地望向远方，东方美学的留白构图，典雅大气，电影风格 |
