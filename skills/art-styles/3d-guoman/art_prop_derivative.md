# 道具衍生模板

## 概述

道具衍生围绕两个核心维度展开：**使用状态**和**视角**。主资产通常为道具的静置正面展示图，衍生资产根据剧情需要生成不同状态或视角的变体。

---

## 一、使用状态变体

### 1.1 静置/佩戴状态
- **描述**：道具处于自然放置或佩戴在角色身上的状态，无外力作用
- **视觉特征**：形态完整，细节清晰，材质原貌呈现
- **适用场景**：道具首次出场展示、角色日常佩戴、物品陈列
- **提示词要点**：强调材质质感、工艺细节、完整造型
- **示例**：`一柄长剑斜插于黑檀木剑架上，剑鞘为墨绿蛇皮纹，鎏金剑格雕龙首，剑穗垂落`

### 1.2 手持/使用中状态
- **描述**：道具被角色握持或正在使用过程中，有运动感或力量传导
- **视觉特征**：与手部互动（手指握合、掌心贴合），可能有轻微运动模糊
- **适用场景**：角色拔剑、翻阅书卷、举杯饮酒、挥笔书写
- **提示词要点**：强调手与道具的接触关系、使用动态、力度感
- **示例**：`右手紧握剑柄，指节泛白，剑身斜指前方，剑刃寒光一闪`

### 1.3 激活/发光状态（法器类）
- **描述**：法器、灵物等特殊道具被灵力/法力激活后的发光/变形状态
- **视觉特征**：自发光效果（光晕、光粒子、纹路亮线），可能伴随形态微变（展开、旋转、悬浮）
- **适用场景**：施法战斗、封印激活、灵器共鸣、认主仪式
- **提示词要点**：强调发光颜色、光晕范围、纹路流动方向、粒子扩散效果
- **示例**：`玉佩悬浮于掌心上方三寸，通体泛起淡青色荧光，表面云纹如活物般流转，细碎光粒子向四周飘散`

### 1.4 损毁/碎裂状态
- **描述**：道具因战斗、意外或剧情需要出现破损、碎裂、灼烧等损坏状态
- **视觉特征**：裂痕、缺口、碎片散落、烧焦痕迹、锈蚀等
- **适用场景**：战后残局、关键道具被毁的剧情转折、时间流逝的象征
- **提示词要点**：强调损毁程度（轻微裂纹 vs 完全碎裂）、破损位置、碎片分布
- **示例**：`长剑断为两截，断口参差不齐，剑身布满蛛网状裂纹，碎片散落于地面，剑格处龙首雕刻仅余半边`

## 二、视角变体

### 2.1 正面展示
- **构图**：道具正面朝向镜头，完整展示主要造型和标志性细节
- **适用场景**：资产目录展示、道具初次登场的特写镜头
- **提示词要点**：正面平视角度，背景干净（纯色或轻微环境），光线均匀突出造型
- **示例**：`正面展示，一面铜镜，镜面光滑如水，镜背雕刻凤凰牡丹纹，底座为莲花形黄铜托架，纯黑背景`

### 2.2 特写细节
- **构图**：微距聚焦道具的某个关键细节（铭文、宝石镶嵌、机关结构）
- **适用场景**：剧情线索揭示、工艺品质展示、悬念伏笔
- **提示词要点**：极浅景深，焦点区域纤毫毕现，背景完全虚化
- **示例**：`特写，剑格处龙首雕刻，龙眼为红色宝石镶嵌，龙须沿剑格两侧延展，鎏金表面微有磨损痕迹，景深极浅`

### 2.3 与角色互动状态
- **构图**：道具与角色同框，重点表现两者之间的空间关系和互动动态
- **适用场景**：角色使用道具的叙事镜头、人物与信物的情感关联画面
- **提示词要点**：明确角色与道具的相对位置、接触方式、情绪关联
- **示例**：`女子双手捧起玉佩至胸前，低眉凝视，玉佩上的青光映照面庞，神情中透出眷恋与伤怀`

## 三、衍生提示词模板

### 3.1 模板结构

```
[道具主体] {从主资产复制的道具基础描述 — 材质、造型、尺寸、核心特征}
[使用状态] {当前状态描述，未变更则写"同主资产（静置）"}
[视角] {当前视角及构图要求，未变更则写"同主资产（正面展示）"}
[变更说明] 本次衍生变更项：{列出变更的维度}
```

### 3.2 示例：「霜华剑」— 激活态特写衍生

**主资产提示词**（静置-正面展示）：
> 正面展示，三尺长剑，剑身银白如霜，剑脊中央一道浅槽贯通，墨绿蛇皮剑鞘，鎏金龙首剑格，白色剑穗，置于黑檀木剑架上。

**衍生提示词**（`prop_shuanghua_d01`，激活态-特写）：
```
[道具主体] 三尺长剑，剑身银白如霜，剑脊中央一道浅槽贯通，鎏金龙首剑格
[使用状态] 激活态，剑身通体泛起冰蓝色寒光，浅槽内有冰晶纹路缓缓流转，剑刃周围冷气凝结为白雾，龙首双目亮起幽蓝光点
[视角] 特写，聚焦剑身中段至剑格区域，景深极浅，冰蓝光晕溢出画面边缘
[变更说明] 本次衍生变更项：使用状态（静置→激活）、视角（正面展示→特写）
```

### 3.3 衍生资产元数据格式

```json
{
  "id": "prop_shuanghua_d01",
  "parentId": "prop_shuanghua",
  "type": "prop_derivative",
  "label": "霜华剑-激活态特写",
  "changedAspects": ["usageState", "viewAngle"],
  "usageState": "activated",
  "viewAngle": "closeup_detail",
  "prompt": "..."
}
```

## 四、注意事项

1. **主体一致性**：所有衍生必须保持道具的核心辨识特征（如霜华剑的银白剑身、龙首剑格），不可因状态变化而丢失
2. **损毁可逆标记**：损毁状态的衍生需标注 `destructive: true`，在剧情时间线管理中确保损毁发生在正确节点之后
3. **激活效果统一**：同一道具的激活发光效果在全剧中保持颜色和风格一致，首次定义后记录在主资产备注中
4. **parentId 必填**：所有衍生资产必须关联主资产，格式为 `{主资产id}_d{序号}`
