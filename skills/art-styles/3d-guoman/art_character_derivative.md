# 角色衍生模板 — L0-L5 六层堆叠体系

## 一、六层堆叠体系说明

角色衍生采用六层堆叠（Layered Stacking）架构，每一层独立可控，组合后构成角色在特定场景下的完整外观。

| 层级 | 名称 | 内容 | 切换时机 |
|------|------|------|----------|
| **L0** | 底模 | 脸型、五官、体型、肤色、身高比例 | **永远不变** — 一致性锚点 |
| **L1** | 妆面 | 素颜 / 淡妆 / 盛装妆容 | 按剧情阶段切换（日常→宴会→战后） |
| **L2** | 发型 | 散发 / 束发 / 盘发 / 编发 | 按场景或身份切换（闺房→朝堂→战场） |
| **L3** | 内衣 | 中衣 / 亵衣 / 寝衣 | 私密场景（寝殿、沐浴、受伤救治） |
| **L4** | 外衣 | 常服 / 战甲 / 礼服 / 官袍 / 丧服 / 斗篷 | 按剧情事件切换（出征、大婚、丧礼） |
| **L5** | 配饰 | 头饰 / 耳饰 / 颈饰 / 腰饰 / 手饰 | 身份标识或仪式标识（封赏、信物交换） |

**层级关系**：L0 → L1 → L2 → L3 → L4 → L5，从内到外依次叠加。生成图像时，提示词按此顺序拼接。

## 二、核心原则

### 2.1 面容锁定
- 所有衍生形态共享同一 L0 底模，面部特征（眼型、鼻梁、唇形、脸型轮廓）不可偏移
- 生成衍生提示词时，L0 描述段必须与主资产完全一致，逐字复制

### 2.2 逐层可控
- 每次衍生只修改需要变化的层，其余层维持与上一状态一致
- 禁止一次性变更超过 3 层（容易导致角色辨识度下降）
- 变更层必须在衍生记录中明确标注

### 2.3 parentId 关联
- 每个衍生资产必须通过 `parentId` 字段链接到主资产
- 衍生资产的 `id` 格式：`{主资产id}_d{序号}`，如 `char_lingyue_d01`
- 主资产删除时，所有关联衍生资产同步标记为失效

### 2.4 同镜禁重
- 同一父资产在同一分镜中禁止主资产与衍生资产同时出现
- 若剧情需要（如回忆对比），必须使用分割画面或转场处理

## 三、服饰组合速查表

以下为按剧情阶段推荐的默认层级搭配，实际使用时可根据剧本需要调整。

### 日常阶段
| 层级 | 推荐选项 |
|------|----------|
| L1 | 素颜 或 淡妆 |
| L2 | 散发 或 简单束发 |
| L3 | — （被 L4 覆盖） |
| L4 | 常服 |
| L5 | 简单发簪 + 腰佩（玉佩/香囊） |

### 战斗阶段
| 层级 | 推荐选项 |
|------|----------|
| L1 | 素颜（战场无暇化妆）或 战妆（眼线加重） |
| L2 | 高束马尾 或 编发 |
| L3 | 中衣（甲胄内衬） |
| L4 | 战甲 / 轻甲 + 护腕 |
| L5 | 额饰/束发冠 + 腰间兵器挂件 |

### 仪式阶段（大婚/封赏/祭祀）
| 层级 | 推荐选项 |
|------|----------|
| L1 | 盛装妆容（唇红、眉黛、腮红） |
| L2 | 盘发（高髻 / 凤髻） |
| L3 | 中衣（礼服内衬） |
| L4 | 礼服 / 官袍 |
| L5 | 全套头饰 + 耳坠 + 项链 + 腰封 + 手镯 |

### 私密阶段（寝殿/沐浴/伤后）
| 层级 | 推荐选项 |
|------|----------|
| L1 | 素颜 |
| L2 | 散发（披肩长发） |
| L3 | 亵衣 / 寝衣 |
| L4 | — （无外衣） |
| L5 | 无 或 仅保留贴身信物（如项链） |

## 四、衍生提示词模板

### 4.1 模板结构

```
[L0-底模] {从主资产完整复制的面容+体型描述}
[L1-妆面] {当前妆面描述，未变更则写"同主资产"}
[L2-发型] {当前发型描述，未变更则写"同主资产"}
[L3-内衣] {当前内衣描述，无则省略}
[L4-外衣] {当前外衣描述，未变更则写"同主资产"}
[L5-配饰] {当前配饰描述，未变更则写"同主资产"}
[变更说明] 本次衍生变更层：{列出变更的层级编号}
```

### 4.2 示例：女主「凌月」— 战斗衍生

**主资产提示词**（日常态）：
> 鹅蛋脸，柳叶眉，丹凤眼含星光，鼻梁挺直，薄唇微抿，身形纤细修长。淡妆，散发及腰，身着浅蓝色常服，腰系白色丝带，佩白玉簪。

**衍生提示词**（战斗态 `char_lingyue_d01`）：
```
[L0-底模] 鹅蛋脸，柳叶眉，丹凤眼含星光，鼻梁挺直，薄唇微抿，身形纤细修长
[L1-妆面] 素颜，眉眼间透出凌厉英气
[L2-发型] 高束马尾，以银色发环固定，碎发拂面
[L3-内衣] 黑色贴身中衣
[L4-外衣] 银白色轻甲，胸口刻有云纹，护臂覆盖前臂，腰甲以暗扣收紧
[L5-配饰] 银色束发环 + 腰间挂短剑穗
[变更说明] 本次衍生变更层：L1、L2、L3、L4、L5
```
