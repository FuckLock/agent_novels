# 分镜表风格约束（3D 国风）

本文件规范分镜师在编写分镜表时必须遵守的光影、动作节奏、运镜和古风特有规则。

---

## 1. 光影统一规则

### 核心原则

同一 scene group 内，光源方向和色调必须保持一致，仅允许明暗程度的微调。

### 具体规则

| 规则 | 说明 | 示例 |
|------|------|------|
| 光源方向锁定 | scene group 首个分镜确定光源方向后，后续分镜不可改变 | 首镜光从左侧入射，则整组分镜光源均从左侧 |
| 色调一致 | 同组分镜的色温保持一致，不可跳变 | 不可从暖黄突然变为冷蓝 |
| 明暗微调范围 | 允许在基础明暗比上下浮动 10% | 基础 6:4 → 允许范围 5.5:4.5 至 6.5:3.5 |
| 景别切换时 | 切换景别不改变光源，只改变光影在画面中的占比 | 全景→特写：光源方向不变，面部受光面积增大 |

### 跨 scene group 光线过渡

- 相邻 scene group 色调差异较小（如 C1→C5）：直接切换
- 相邻 scene group 色调差异较大（如 C7→C4）：插入 1 个过渡分镜，使用中间色调
- 室内外转换：利用门窗、廊道等建筑元素作为光线过渡的叙事载体

## 2. 古风动作节奏

### 2.1 武打戏——快慢交替

武打戏采用"蓄力→爆发→定格"三段式节奏：

| 阶段 | 节奏 | 时长占比 | 分镜要求 |
|------|------|---------|---------|
| 蓄力 | 慢速 | 30% | 中景或近景，展示角色准备姿态、眼神变化、握紧武器 |
| 出招 | 急速 | 50% | 快切多镜头，每个分镜 0.5-1 秒，动作连贯不重复（注：快切节奏在分镜表中表达为多条短 shot，实际视频在 Track 级合成时编织为连续运动序列） |
| 定格亮相 | 静止 | 20% | 全景或中景，角色定格在收招姿态，衣袂/发丝余波未平 |

**武打分镜规则**：
- 蓄力阶段必须有至少 1 个面部特写，展示眼神中的杀意或决心
- 出招阶段每个分镜只展示一个动作，不在单镜中堆叠多个连续动作
- 定格亮相时背景留白或虚化，突出角色剪影
- 武器碰撞/格挡用特写捕捉接触瞬间

### 2.2 文戏——缓慢沉稳

文戏强调"眼神→微表情→走位"的递进节奏：

| 阶段 | 节奏 | 时长占比 | 分镜要求 |
|------|------|---------|---------|
| 视线交流 | 缓慢 | 30% | 近景或特写，两人对视，捕捉眼神中的情绪变化 |
| 微表情 | 极缓 | 40% | 特写，展示嘴角、眉头、睫毛等细微动作 |
| 缓步走位 | 缓慢 | 30% | 中景或全景，角色缓慢移动，带出环境信息 |

**文戏分镜规则**：
- 单个分镜时长 2-4 秒，给观众充分感受情绪的时间
  > 注：此为分镜表规划时长（shot 级），实际视频在 Track 级合成（单个 Track 7-15s 整数秒）。多个文戏 shot 在 C3 阶段合成为一段连贯的对话/情感场景视频。
- 对话场景中，说话者和倾听者的分镜比例约 4:6（多拍反应）
- 角色走位时利用环境道具（茶盏、折扇、棋子）辅助表达情绪
- 沉默段落用环境空镜（窗外落叶、水中倒影）填充，不留空白

### 2.3 仪式戏——庄重缓慢

仪式场景（婚礼、祭祀、登基、拜师等）采用"远观→渐近"的节奏：

| 阶段 | 节奏 | 时长占比 | 分镜要求 |
|------|------|---------|---------|
| 全景铺陈 | 极缓 | 40% | 大全景或全景，展示仪式全貌、场地布置、人物阵列 |
| 逐步推近 | 缓慢 | 35% | 中景→近景，逐步聚焦主要人物 |
| 关键时刻 | 缓慢 | 25% | 特写，捕捉关键动作（跪拜、交杯、递物） |

**仪式分镜规则**：
- 开场全景必须停留足够时间（3 秒以上），让观众感受场面
- 推近过程保持匀速，不可突然跳切
- 关键仪式动作用正面或微侧角度拍摄，保持庄重感
- 围观人群的反应镜头穿插其中，增强仪式感

## 3. 运镜禁区

### 3.1 禁止的运镜方式

| 禁止运镜 | 原因 | 替代方案 |
|----------|------|---------|
| 快速甩镜（whip pan） | 破坏古风沉稳气质，视觉突兀 | 用缓推或跟移代替 |
| 频繁变焦（zoom in/out） | 产生廉价感，不符合电影质感 | 用物理推拉（dolly）代替 |
| 360 度旋转 | 炫技感过强，分散注意力 | 最多使用 90-120 度弧线移动 |
| 手持晃动模拟 | 与 3D 渲染质感不匹配 | 保持稳定运镜 |
| 无动机运镜 | 运镜必须有叙事理由 | 每次运镜标注叙事目的 |

### 3.2 推荐的运镜方式

| 推荐运镜 | 效果 | 适用场景 | 速度要求 |
|----------|------|---------|---------|
| 缓推（slow push in） | 增强情绪压迫感、聚焦重点 | 对话高潮、情绪爆发前、揭示真相 | 2-4 秒完成 |
| 缓拉（slow pull out） | 揭示环境、增加孤独感 | 独处、离别后、场景结束 | 3-5 秒完成 |
| 跟移（tracking shot） | 陪伴感、空间展示 | 角色行走、穿过建筑、巡视 | 匹配角色步速 |
| 固定机位 | 沉稳、客观、仪式感 | 对话、仪式、等待 | 不动 |
| 微摇（slight pan） | 自然视线转移 | 角色转头看向某物、视线引导 | 1-2 秒完成 |
| 升降（crane shot） | 俯视全局、揭示规模 | 战场、宫殿、仪式场面 | 3-5 秒完成 |

## 4. 古风特有分镜规则

### 4.1 飞天/腾空场景

适用于轻功、跳跃、凌空打斗等场景：

| 要素 | 规则 |
|------|------|
| 机位角度 | **仰拍为主**，从地面或低位向上拍摄，强调腾空高度和气势 |
| 速度处理 | **慢镜**处理，放慢至 0.3-0.5 倍速，展示衣袂飘扬和身姿舒展 |
| 背景选择 | 以天空、云层、月亮、飞檐为背景，增强飘逸感 |
| 辅助元素 | 落叶、花瓣、水珠等随人物动作飞散，增加动态层次 |
| 着陆收尾 | 落地瞬间恢复正常速度，用定格展示落点姿态 |

**示例分镜**：
> 仰拍视角，她纵身跃起的身影逐渐远离地面，月白色衣裙在空中徐徐展开如飞天画卷，几片花瓣随气流盘旋上升，背后一轮圆月映衬出她舒展的剪影

### 4.2 打斗场景

适用于武斗、追杀、比武等场景：

| 要素 | 规则 |
|------|------|
| 剪辑节奏 | **快切为主**，单镜 0.5-1.5 秒，营造紧张感 |
| 长镜穿插 | 每 4-6 个快切后穿插 1 个 3-4 秒的长镜头，让观众喘息 |
| 景别分配 | 全景展示走位（20%）、中景展示招式（50%）、特写展示表情和武器（30%） |
| 对打节奏 | 双方交替出镜，不可连续 3 个以上镜头只拍同一角色 |
| 高潮处理 | 最后一击用蓄力慢镜→急速出招→定格的三段式 |

**示例分镜**：
> 快切：他右掌推出——对手侧身闪避——剑锋划过衣角——
> 长镜：两人拉开距离，各自调整呼吸，衣衫猎猎，对峙片刻
> 快切：她突然欺身而上——剑影连闪三次——

### 4.3 对话场景

适用于日常对话、密谈、争论等场景：

| 要素 | 规则 |
|------|------|
| 基础机位 | **正反打**（shot/reverse shot）为主体结构 |
| 辅助机位 | **过肩镜头**穿插使用，增加空间感和亲密感 |
| 机位高度 | 平视为主；地位高者可用微仰，地位低者可用微俯 |
| 倾听者 | 每轮对话至少 1 个倾听者反应镜头（微表情、手部动作） |
| 情绪升级 | 对话情绪升级时，景别从中景逐步推近至近景、特写 |
| 沉默时刻 | 用空镜（茶杯冒烟、烛火摇曳）或手部特写填充 |

**正反打节奏参考**：
```
A说（近景A） → B反应（过肩看B） → B说（近景B） → A反应（过肩看A）
     → 双人中景（展示空间关系） → 继续正反打...
```

### 4.4 其他古风特有场景

| 场景类型 | 机位/运镜 | 节奏 | 关键要素 |
|---------|----------|------|---------|
| 书信/读诗 | 特写手持书信 → 缓推至文字 → 拉出看读信人表情 | 极缓 | 纸张质感、毛笔字迹、手指微颤 |
| 抚琴/吹笛 | 中景全貌 → 手部特写 → 面部特写 → 缓拉至全景 | 缓慢 | 手指拨弦细节、闭眼沉醉的表情 |
| 饮酒/品茶 | 特写倒酒/斟茶 → 端杯近景 → 对饮中景 | 缓慢 | 液体流动、杯盏质感、饮后微表情 |
| 策马奔驰 | 跟移侧拍 → 俯拍马队 → 正面迎拍 | 快速 | 马蹄扬尘、鬃毛飞扬、披风猎猎 |
| 登高远望 | 背影中景 → 缓拉至大全景 → 正面近景 | 缓慢 | 风吹衣袂、远山层叠、角色眼中映景 |
