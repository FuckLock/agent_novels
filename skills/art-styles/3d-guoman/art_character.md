## 四、四视图设定图规范

### 布局定义

| 区域 | 占比 | 内容 | 景别 | 要求 |
|------|------|------|------|------|
| 左半 50% | 面部特写 | 正面平视 | 头顶至锁骨 | 面部占画面 60% 以上，五官清晰可辨，从头顶到锁骨完整展示，严禁裁切头顶 |
| 右半 50% 左 | 正面全身 | 正面 0° | 全身立像 | 面对镜头、双臂自然下垂、从头顶到脚底完整展示 |
| 右半 50% 中 | 侧面全身 | 右侧 90° | 全身立像 | 纯侧面轮廓清晰、从头顶到脚底完整展示 |
| 右半 50% 右 | 背面全身 | 后方 180° | 全身立像 | 后脑/背部/发尾/脚部清晰、从头顶到脚底完整展示 |

### 画面技术规范

| 项目 | 约束 |
|------|------|
| 分辨率 | 8K 超高清渲染 |
| 背景 | 白色纯净背景（#FFFFFF），无任何环境元素 |
| 渲染引擎 | UE5 级别实时渲染画质 |
| 材质体系 | PBR（物理渲染）材质，金属度/粗糙度/法线贴图完整 |
| 皮肤渲染 | SSS（次表面散射）皮肤渲染，耳廓/指尖/鼻翼可见暖色透光 |
| 轮廓光 | 边缘轮廓光（Rim Light）勾勒角色轮廓，增强立体感 |
| 主光源 | 前方柔光 + 双侧补光，无硬阴影 |
| 站姿 | 自然站立、双脚平行微分、双臂自然下垂 |
| 表情 | 中性微表情，符合角色核心气质 |
| 一致性 | 四视图的面容/肤色/体型/发型/服装/配饰完全一致 |
| 文字 | 画面中不得出现任何文字、标注、水印 |

## 六、约束规则

### 必守规则

| 编号 | 规则 |
|------|------|
| R1 | 面容必须从约束表中选择，不得自由发挥超出选项范围 |
| R2 | 气质类型必须明确声明，且与面容/体态选择逻辑自洽 |
| R3 | 身高和头身比必须明确声明，且符合体型分类表的范围 |
| R4 | 肤色统一为暖黄色系（参考 prefix.md 色板），禁止冷白/灰白 |
| R5 | 四视图布局必须严格遵循：左半面部特写 + 右半三个全身 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 面部特写必须从头顶到锁骨完整展示，严禁裁切头顶 |
| R8 | 背景必须为白色纯净背景，无环境元素 |
| R9 | 必须包含 UE5/PBR/SSS/轮廓光 等技术关键词 |
| R10 | 画面中不得出现任何文字、标注、水印 |

### 严禁项

| 编号 | 严禁 |
|------|------|
| X1 | 使用真人照片或写实面部特征（毛孔/雀斑/虹膜纹路） |
| X2 | 面部描写使用静态写实细节，应使用情绪动态方式 |
| X3 | 出现任何现代元素（参考 prefix.md 禁止项） |
| X4 | 正顶硬光/正底光/冷色光 |
| X5 | 过度美白至无血色 / 肤色发灰 |
| X6 | 夸张表情/动态姿势（设定图应为中性站姿） |
| X7 | 同一角色四视图间出现不一致（面容/服装/体型/发型） |
| X8 | 复杂场景背景（必须白色纯净） |
