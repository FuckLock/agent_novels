## 二、构图规范

### 2.1 透视类型

| 透视 | 适用场景 | 说明 |
|------|----------|------|
| 一点透视 | 大殿/官道/长廊/甬道 | 纵深感强，强调空间延伸，消失点居中或偏移 |
| 两点透视 | 建筑群/街道/客栈外景 | 呈现建筑体量感，适合展示建筑转角关系 |
| 三点透视 | 高塔/悬崖/仙府全貌 | 增加戏剧张力，适合宏大场景 |
| 俯视 | 战场/集市/山门广场/阵法 | 展示空间布局与人群动线，信息量大 |
| 仰视 | 悬崖/大殿内部/巨木/瀑布 | 强调高度与压迫感，营造敬畏情绪 |

### 2.2 构图法则

| 法则 | 说明 | 适用场景 |
|------|------|----------|
| 三分法 | 关键元素放置于三分线交叉点，避免绝对居中 | 通用，所有场景默认使用 |
| 对称构图 | 中轴对称，强调庄严/仪式/秩序感 | 大殿/山门/阵法空间/仙府 |
| 引导线构图 | 利用道路/河流/台阶/廊柱引导视线至焦点 | 官道/长廊/瀑布/悬崖 |
| 框架构图 | 利用门洞/窗棂/树冠/山洞作为天然画框 | 室内向外/洞口/拱门 |

### 2.3 空间层次（硬约束）

每张场景设定图 **至少包含两层空间层次**，推荐三层：

| 层次 | 作用 | 典型元素 |
|------|------|----------|
| 前景 | 增加纵深感，框定画面 | 树枝/栏杆/飘落花瓣/柱体/岩石 |
| 中景 | 承载主体信息，叙事核心区 | 建筑主体/角色活动区/关键道具 |
| 背景 | 交代环境、营造氛围 | 远山/天空/云海/建筑群剪影 |

> **规则**：前景与背景之间必须有明确的明暗/色彩/清晰度差异，以体现空气透视效果。远处物体色彩偏冷、饱和度降低、细节减少。

## 三、光影规范

### 3.1 光源类型

#### 自然光
| 光源 | 色温 | 特征 |
|------|------|------|
| 清晨日光 | 3500K-4500K（暖橙） | 低角度长投影，金色调，适合宁静/希望场景 |
| 正午日光 | 5500K-6000K（中性白） | 短投影，高对比度，适合热闹/日常场景 |
| 黄昏日光 | 2700K-3500K（暖红橙） | 极低角度，长影，强烈暖色，适合离别/壮阔场景 |
| 月光 | 7000K-8500K（冷蓝） | 柔和低照度，蓝色调，适合神秘/抒情场景 |
| 阴天漫射 | 6500K-7000K（冷灰） | 无明显投影，柔光均匀，适合肃杀/压抑场景 |

#### 人工光/法术光
| 光源 | 色温/色相 | 特征 |
|------|-----------|------|
| 灯笼/烛火 | 2200K-2700K（暖黄橙） | 点光源，柔和衰减，营造温馨/古朴感 |
| 火把/篝火 | 2000K-2500K（暖橙红） | 闪烁动态，投影摇曳，适合洞窟/夜间 |
| 法术光（暖系） | 朱砂红/赤金色 | 自发光+粒子，无自然衰减，适合战斗/仪式 |
| 法术光（冷系） | 青翠绿/靛蓝 | 自发光+粒子，冷色调，适合结界/治愈/幻境 |

### 3.2 光源方向

| 方向 | 效果 | 适用场景 |
|------|------|----------|
| 正面光 | 平坦，信息清晰但缺乏立体感 | 仅用于说明性场景图，**不推荐** |
| 侧光 | 强调体积感与纹理，明暗分明 | **推荐**，通用于大部分场景 |
| 逆光 | 轮廓光勾勒边缘，剪影效果，戏剧感强 | **推荐**，适合壮阔/神秘/仪式场景 |
| 顶光 | 垂直投影，强调高度感 | 大殿/森林/竹林 |
| 底光 | 非自然，诡异/恐怖感 | 法阵/地火/深渊 |

### 3.3 色温范围

| 色温区间 | 情绪 | 对应场景 |
|----------|------|----------|
| 暖色（2000K-3500K） | 温馨/古朴/战斗/仪式 | 室内烛光、黄昏、火焰、暖系法术 |
| 中性（4500K-6000K） | 日常/平静/叙事 | 正午日光、阴天、一般室外 |
| 冷色（6500K-8500K） | 神秘/孤寂/肃杀/悲伤 | 月光、冰雪、深夜、冷系法术 |

### 3.4 阴影规则（硬约束）

- **禁止纯黑阴影**：画面最深处禁止使用 `#000000`
- 室内阴影最深色：**深褐色** `#1E1510`（暖光源环境）
- 室外阴影最深色：**深蓝灰** `#141828`（自然光环境）
- 法术场景阴影最深色：**深紫墨** `#18102A`（法术光环境）
- 所有阴影必须保留可辨识的色彩倾向，与光源色温互补

## 四、材质与氛围规范

### 4.1 建筑材质

| 材质 | 渲染要求 | 典型应用 |
|------|----------|----------|
| 木 | 年轮纹理可见，表面有自然氧化色差，榫卯结构处可见接缝 | 客栈/书房/廊柱/门板 |
| 石 | 风化纹理，青苔附着于北面/阴面，棱角圆润磨损 | 台阶/牌坊/假山/城墙 |
| 砖 | 灰砖/青砖纹路清晰，砖缝有灰浆填充，部分脱落 | 院墙/地面/影壁 |
| 瓦 | 筒瓦/板瓦排列规整，有雨水冲刷痕迹，屋脊有兽首装饰 | 屋顶/飞檐/瓦当 |
| 竹 | 竹节分明，表面有自然光泽，断口处纤维可见 | 竹屋/竹篱/竹桥/竹林 |

### 4.2 装饰纹样

| 纹样 | 应用位置 | 设计约束 |
|------|----------|----------|
| 云纹 | 栏杆/柱础/法器/建筑边饰 | 流线圆润，禁止棱角锐利 |
| 龙凤 | 大殿/御座/重要法器/仪式场景 | 仅用于高等级场景，不可滥用 |
| 几何纹 | 窗棂/地砖/屏风/围栏 | 规整对称，以回纹/万字纹/冰裂纹为主 |
| 花卉 | 闺阁/屏风/瓷器/服饰绣样 | 梅兰竹菊/莲花/牡丹，符合场景气质 |
| 水墨 | 屏风画/壁画/卷轴/背景远山 | 留白大于50%，笔触简洁写意 |

### 4.3 氛围元素

| 元素 | 渲染要求 | 适用场景 |
|------|----------|----------|
| 体积雾 | 浓度由近及远递增，底部偏浓顶部稀薄，颜色跟随环境色温 | 山川/森林/仙府/清晨 |
| 飞花 | 花瓣大小随距离缩小，近处清晰远处虚化，运动方向一致 | 春季/桃林/闺阁/仙境 |
| 落叶 | 黄/红/褐色为主，翻转角度随机，少量积于地面 | 秋季/官道/竹林/战后 |
| 尘埃 | 微粒在光束中可见（丁达尔效应），密度适中不遮挡主体 | 室内光束/废墟/密室 |
| 火星 | 橙红色微粒，向上飘散，尾迹渐灭 | 篝火/锻造/战场/火灾 |
| 法术粒子 | 颜色与法术属性一致，有轨迹运动（非静止），带微弱发光 | 阵法/秘境/战斗/修炼 |

## 五、四视图设定图规范

### 5.1 视图定义

> 摄像机固定于场景中心点，分别朝前/后/左/右四个方向拍摄，形成 360° 环视。

| 位置 | 视图 | 视角方向 | 要求 | 提示词 |
|------|------|----------|------|--------|
| 左上 | 前视图 | 从中心点向前方平视（0°） | 展示场景正面主体结构与纵深层次 | front view、eye level、looking forward |
| 右上 | 右视图 | 从中心点向右方平视（90°） | 展示场景右侧空间延伸与侧面结构 | right side view、eye level、looking right |
| 左下 | 后视图 | 从中心点向后方平视（180°） | 展示场景背面结构与空间纵深 | back view、eye level、looking backward |
| 右下 | 左视图 | 从中心点向左方平视（270°） | 展示场景左侧空间延伸与侧面结构 | left view、eye level、looking left |

### 5.2 画面规范

| 项目 | 约束 |
|------|------|
| 布局 | 同一画面 2×2 网格排列：上排（前视图 + 右视图），下排（后视图 + 左视图），形成从中心点环视的四方向视图 |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 视点 | 四视图均从同一中心点出发，视线高度一致（人眼平视高度） |
| 一致性 | 四视图的建筑结构/材质/色调/光线/季节/天候完全一致 |
| 光线 | 四视图光源方向统一，保持光影逻辑一致（光源在不同视角下的位置关系正确） |
| 分辨率 | 8K 超高清渲染 |
| 材质 | PBR 物理材质体系 |
| 光影 | 必须包含体积光（Volumetric Lighting） |
| 画面比例 | 1:1（2×2 网格） |

### 5.3 标注要求

场景设定图应在描述中明确标注以下关键区域：

- **入口/出口**：角色进出场景的位置
- **视觉焦点**：画面的核心视觉中心（如主建筑、瀑布、法阵中心）
- **空间层次**：标注前景/中景/背景的主要元素
- **光源位置**：主光源方向与辅助光源位置

### 5.4 色调一致性

- 同一项目内的场景色调必须与 `prefix.md` 色板保持一致
- 场景色调需服务于叙事情绪：暖色调用于温馨/战斗段落，冷色调用于悲伤/神秘段落
- 同一集内的场景色调过渡需平滑，避免相邻场景色温跳跃超过 2000K

## 七、约束规则

### 必守

| 编号 | 规则 |
|------|------|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」 |
| R3 | 场景图必须为「四视图设定图」（从中心点环视：前视图 + 右视图 + 后视图 + 左视图，2×2 网格布局） |
| R4 | 四视图的建筑结构/材质/色调/光线/季节/天候必须完全一致 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含 3D 渲染关键词（3D rendered / volumetric lighting / PBR materials） |
| R7 | 必须包含镜头光学特征（depth of field / lens vignette / bokeh 至少一项） |
| R8 | 材质必须带有自然磨损/岁月痕迹，禁止全新无瑕的"CG 感" |

### 严禁

| 编号 | 严禁 |
|------|------|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 四视图之间建筑结构/材质/色调不一致，或视点中心不统一 |
| X7 | 使用 2D/赛璐璐/卡通等与 3D 国漫风格冲突的关键词 |
| X8 | 材质过于干净完美、无任何使用痕迹与岁月感（避免"塑料感"） |
| X9 | 光照过于均匀平坦、无景深虚化、无镜头光学特征 |

### 约束优先级

1. **prefix.md 全局硬约束**（最高优先级）
2. **本文件硬约束**（场景层约束）
3. **本文件软约束/推荐**（优先遵守但可根据叙事需要适度调整）
4. **具体项目设定**（项目级覆盖，需在项目 config 中声明）

> 当本文件规范与 `prefix.md` 冲突时，以 `prefix.md` 为准。
