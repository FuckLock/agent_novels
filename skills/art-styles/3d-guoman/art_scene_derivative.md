# 场景衍生模板 — 三维度衍生体系

## 概述

场景衍生基于三个独立维度：**景别**、**时段**、**天气**。每个维度各有若干预设变体，按剧本实际需求按需组合生成，不必穷尽所有排列。

主资产定义场景的空间结构与核心元素，衍生资产在此基础上调整镜头距离、光影氛围或天气效果。

---

## 一、景别维度

景别决定镜头与场景的距离关系，影响构图、信息密度和情绪表达。

### 1.1 远景（Extreme Wide Shot）
- **构图特点**：场景全貌，建筑/地形占画面主体，人物极小或不可见
- **适用场景**：开篇定调、转场过渡、展现地理环境规模
- **提示词要点**：强调天际线、整体轮廓、大气透视感
- **示例差异**：`远景俯瞰，群山环绕的古城全貌，城墙蜿蜒，晨雾缭绕，大气磅礴`

### 1.2 全景（Wide Shot）
- **构图特点**：完整展示场景主体（如一座宫殿、一个庭院），人物可辨但非重点
- **适用场景**：新场景首次出现、群戏、大场面
- **提示词要点**：建筑完整呈现，地面/天空留白适当
- **示例差异**：`全景，宫殿正门，红墙金瓦，台阶两侧石狮，数名侍卫列队`

### 1.3 中景（Medium Shot）
- **构图特点**：场景局部（一间房的某个区域），人物与环境各占一半
- **适用场景**：对话场景、日常互动、叙事推进
- **提示词要点**：保留关键环境元素（桌椅、窗户），背景适度虚化
- **示例差异**：`中景，书房一角，红木书案上文房四宝，窗外竹影摇曳`

### 1.4 近景（Close-Up Shot）
- **构图特点**：聚焦场景中某个局部元素（门楣雕花、桌上的物件）
- **适用场景**：细节暗示、情绪渲染、道具特写的背景
- **提示词要点**：景深极浅，焦点元素清晰，背景大幅虚化
- **示例差异**：`近景，案上青铜香炉，袅袅青烟升起，背景虚化为暖色书架`

### 1.5 特写（Extreme Close-Up）
- **构图特点**：极致放大某个细节（雕刻纹样、门锁机关、墙面裂痕）
- **适用场景**：悬念线索、质感表现、象征性画面
- **提示词要点**：微距质感，材质细节（木纹、铜锈、丝绸纹理）
- **示例差异**：`特写，门环上的兽面铜雕，铜绿斑驳，雨珠挂在獠牙尖端`

## 二、时段维度

时段决定光源方向、色温和整体氛围，是情绪塑造的核心手段。

### 2.1 晨（日出至辰时）
- **光影**：低角度侧光，长投影，光线柔和带金色
- **色温**：暖黄偏橙（约 3500K）
- **氛围**：清新、希望、新生
- **色彩规律**：高光偏金，阴影偏紫蓝，天空渐变橙→浅蓝
- **提示词要点**：`晨光熹微，金色阳光从东侧低角度射入，长影拖曳，空气中浮尘可见`

### 2.2 午（巳时至未时）
- **光影**：顶光或高角度光，投影短而浓重，对比度高
- **色温**：正白偏冷（约 5500K）
- **氛围**：明朗、炽烈、暴露感
- **色彩规律**：色彩饱和度最高，白色区域刺眼，暗部边界锐利
- **提示词要点**：`正午烈日当空，光线直射，阴影浓缩于脚下，色彩鲜明通透`

### 2.3 暮（申时至酉时）
- **光影**：低角度逆光/侧逆光，轮廓光强烈，氛围感最佳
- **色温**：暖橙偏红（约 2500K）
- **氛围**：离别、伤感、壮美、沉思
- **色彩规律**：天空橙红→紫蓝渐变，地面物体被暖光镀上金边
- **提示词要点**：`夕阳西沉，橙红余晖洒满庭院，人物剪影轮廓镶金边`

### 2.4 月夜（戌时至子时·有月）
- **光影**：冷色高位散射光，投影淡而柔，明暗反差低
- **色温**：冷蓝偏银（约 7000K）
- **氛围**：静谧、神秘、浪漫、孤独
- **色彩规律**：整体偏蓝灰，白色物体泛银光，暖色被压制
- **提示词要点**：`月光如水，银白冷光从天幕倾泻，庭院笼罩在静谧蓝调中`

### 2.5 灯火夜（戌时至子时·室内/灯笼）
- **光影**：多点暖色光源（灯笼/烛火），明暗交错，投影多方向
- **色温**：暖橙（约 2000K）
- **氛围**：温馨、暧昧、热闹（灯会）、阴谋（密室）
- **色彩规律**：光源周围暖橙色圈，远处迅速衰减至深暗，明暗交界处气氛最强
- **提示词要点**：`烛火摇曳，暖橙色光晕映照近处面容，远处没入深邃暗影`

## 三、天气维度

天气影响能见度、材质表现和画面情绪层次。

### 3.1 晴
- **视觉效果**：通透清澈，远景清晰可辨，天空湛蓝
- **材质影响**：金属高光锐利，丝绸反光明显，石材纹理清晰
- **光影影响**：投影边界清晰，明暗对比最高
- **提示词要点**：`万里无云，天空澄澈，光线通透，远处山峦轮廓分明`

### 3.2 阴
- **视觉效果**：整体灰调，光线均匀散射，无明显投影
- **材质影响**：色彩饱和度降低，金属光泽减弱，木石材质显得沉闷
- **光影影响**：几乎无投影，明暗反差极低，画面偏平
- **提示词要点**：`阴云密布，天光昏沉，万物笼罩在均匀灰光中，色彩沉郁`

### 3.3 薄雾
- **视觉效果**：近景清晰、中景朦胧、远景隐没，层次感极强
- **材质影响**：表面附着水汽微粒，木面微润，金属表面凝结细密水珠
- **光影影响**：光线散射增强，投影边缘模糊，整体柔化
- **提示词要点**：`薄雾弥漫，近处景物清晰，远处楼阁若隐若现，空气中水汽流动`

### 3.4 细雨
- **视觉效果**：雨丝可见，地面积水反光，整体色调偏冷偏暗
- **材质影响**：所有表面湿润反光增强，石板路面如镜面，衣料颜色加深
- **光影影响**：光源周围产生雨雾光晕，投影被打碎
- **提示词要点**：`细雨纷纷，雨丝斜落，青石板地面积水映出倒影，屋檐雨帘如珠`

### 3.5 飘雪
- **视觉效果**：雪花飘落，地面/屋顶覆白，整体高亮低饱和
- **材质影响**：积雪覆盖遮蔽底部材质，露出部分与白雪高对比，红墙/黑瓦效果最佳
- **光影影响**：雪面大面积反光，环境光提亮，投影偏蓝紫
- **提示词要点**：`大雪纷飞，琼瑶碎玉漫天，红墙上积雪皑皑，黑瓦白边，静谧肃穆`

## 四、组合规则

### 4.1 按需生成
- 不要求穷尽 5×5×5 = 125 种组合
- 仅在剧本分镜明确需要时，按实际需求生成特定组合
- 优先生成剧情高频组合（如：宫殿-中景-暮-晴）

### 4.2 主资产定义
- 主资产选择该场景最常出现的默认组合（通常为：全景-午-晴）
- 衍生资产记录与主资产的差异维度

### 4.3 维度优先级
- 景别 > 时段 > 天气（当三个维度同时变化时，景别对构图影响最大，优先确定）

### 4.4 四视图布局
- 衍生场景图同样遵循四视图 2×2 网格布局（从中心点环视：前视图 + 右视图 + 后视图 + 左视图）
- 例外：景别为「特写」「近景」的衍生，使用单视图即可，无需四视图网格

### 4.5 禁止组合
- 无特殊剧情需要时，避免低可读性组合（如：远景+月夜+薄雾 → 几乎看不清场景）

## 五、衍生提示词模板

### 5.1 模板结构

```
[空间结构] {从主资产复制的场景空间描述 — 建筑、地形、核心元素}
[景别] {当前景别及构图要求，未变更则写"同主资产"}
[时段] {当前时段的光影/色温描述，未变更则写"同主资产"}
[天气] {当前天气的视觉效果描述，未变更则写"同主资产"}
[变更说明] 本次衍生变更维度：{列出变更的维度}
```

### 5.2 示例：「御书房」— 暮雨衍生

**主资产提示词**（全景-午-晴）：
> 全景，皇宫御书房，红木梁柱，金色龙纹屏风居中，两侧书架顶天，正午阳光从高窗射入，光柱照亮案上奏折。

**衍生提示词**（`scene_yushufang_d01`，中景-暮-细雨）：
```
[空间结构] 皇宫御书房，红木梁柱，金色龙纹屏风，两侧书架顶天
[景别] 中景，聚焦龙案区域，屏风与左侧书架作为背景框架
[时段] 暮色时分，橙红余晖从高窗斜射，在地面拉出长条光斑，室内整体偏暖暗调
[天气] 窗外细雨，雨声隐约，高窗玻璃上雨痕流淌，室内烛火已点燃
[变更说明] 本次衍生变更维度：景别、时段、天气
```

```json
  "framing": "medium",
  "timeOfDay": "dusk",
  "weather": "light_rain",
  "prompt": "..."
}
```
