# 情绪→面部/眼部映射表

> 用途：在分镜提示词 L3 层情绪面部描写时查此表，将抽象情绪转化为具体可渲染的面部/眼部特征描述。

## 使用规则

### 1. 查表时机

在编写分镜提示词 L3 层（蒙太奇叙事核心）时，当需要描写角色情绪表现，必须查此表获取对应的面部和眼部特征描述，禁止自由发挥。

### 2. 基本用法

**步骤**：
1. 从分镜表的 `emotion` 字段确定当前情绪
2. 在映射表中找到对应行
3. 将面部特征和眼部特征融入叙事段落

**示例**：

分镜表 emotion 字段为"隐忍"时，L3 叙事写法：

```
2-5s：叶真缓缓转身，唇紧抿、下颌微收，眼神沉稳微微眯起，目光越过萧炎的肩头望向远方。
```

### 3. 柔化版使用场景

当提示词经合规审核后触发平台内容红线（Seedance 2.0 或 Gemini 审核），用柔化版替代原版：

**示例——愤怒情绪**：

原版（首选）：
```
叶真眉头紧蹙、嘴角下沉，目光凌厉地逼视对面的长老。
```

柔化版（审核触发时替代）：
```
叶真眉头微蹙、神情严肃，目光锐利地注视对面的长老。
```

### 4. 复合情绪处理

当角色情绪为复合型（如"悲伤中带着决绝"），取两种情绪的特征各一部分组合：

**示例——悲伤+决绝**：
```
叶真眉尾微垂、唇角微颤（取悲伤面部），但目光坚定前视（取决绝眼部），仿佛已做好决定。
```

**组合规则**：
- 面部取主情绪（戏份占比大的那个）
- 眼部取次情绪（提供反差或层次）
- 如果两种情绪面部/眼部冲突严重，以叙事逻辑为准，选择更符合剧情当下状态的组合

### 5. 情绪转换镜头

当同一条分镜内角色情绪发生转变（如从"温柔"转为"决绝"），按时间轴分段描写：

**示例**：
```
0-3s：叶真唇角微扬、面部放松，目光柔和略带笑意地注视着少女。
3-5s：忽然，他的嘴唇缓缓抿紧成线，目光从柔和转为坚定前视——
```

**规则**：
- 情绪转换点必须有0.5-1s的过渡描写
- 过渡段用"缓缓""渐渐"等词连接，禁止瞬间跳变（除非剧情要求"猛然"变化）
- 转换过渡段不需要查表，用自然语言衔接即可

### 6. 禁止事项

- **禁止**使用映射表之外的面部描写词（如"脸色煞白""面如死灰""青筋暴起"）
- **禁止**使用"瞳孔放大""瞳孔收缩"等生理细节词（AI 视频生成无法精确控制瞳孔）
- **禁止**描写泪水、汗水等液体（"眼眶含泪"→ 改为"眼神涣散、目光低垂"）
- **禁止**描写面部颜色变化（"脸颊泛红""面色发青"）——3D 渲染中颜色变化不可控
