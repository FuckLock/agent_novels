# Seedance 导演分析技能

[任务与边界]
    做：
    - 将剧本/梗概/分场大纲拆解为剧情点（P01、P02 …），每个剧情点 = 一段完整叙事 = 一次 Seedance 2.0 生成任务
    - 为每个剧情点撰写"导演阐述"（画面 / 动作 / 台词 / 镜头 / 光影五维度融合）
    - 提取并维护本集人物清单、场景清单、道具清单（含素材状态：新增/复用/变体）
    - 与已有 `novels/{name}/seedance/assets.json` 比对，标记跨集复用 / 变体

    不做：
    - 不写图像生成提示词（属 seedance-asset 阶段 B）
    - 不构建分镜表 / 分镜提示词（属 seedance-storyboard-table / seedance-storyboard-skill）
    - 不下达美术风格细节（仅描述视觉关键词，画风模板由 seedance-asset 加载）
    - 不删改 `novels/{name}/seedance/assets.json`（只读比对）

    完成标准：
    - 产出 `novels/{name}/seedance/ep{N}/01-director.md`，结构含 4 个段落：
      `## 导演讲戏本` / `## 人物清单` / `## 场景清单` / `## 道具清单`
    - 每个剧情点导演阐述 ≥ 3-5 句，含具体物理动作、明确镜头方向、具体光影描述
    - 三类清单中每行都含「素材状态」列，无空值
    - 即使本集无独立道具，也必须输出「## 道具清单」段落（表格写"本集无符合标准的独立道具"）

[第一性原则]（优先级从高到低）
    1. 一段一任务
       一个剧情点 = 一段完整叙事 = 一次 Seedance 2.0 生成任务。段内可有多组镜头，但叙事上必须是一个完整段落。两个相邻段落服务同一叙事目的 → 合并；一个段落含两个独立叙事目的 → 拆分。
    2. 讲戏可执行
       用具体物理动作而非抽象概念（"揉太阳穴"✓，"表现疲惫"✗）；镜头运动有明确方向（"从侧脸推向窗外"✓，"镜头移动"✗）；光影具体到光源与色调（"冷白荧光灯打在脸上"✓，"灯光"✗）。情绪通过动作与环境传达，不直接说"她很伤心"。
    3. 节拍密度遵循 1 拍 ≈ 2.5 秒
       每个连续镜头内：1 个物理动作 / 1 次镜头运动 / 1 句短台词（≤10 字）= 1 拍；同时发生的事合并为 1 拍。多镜头段落把节拍分布在镜头切换中，每个子镜头各自遵守密度上限。
    4. 三清单完整不漏
       人物 / 场景 / 道具三段必须全部输出。下游 seedance-asset 依赖三清单提取资产，缺一个 → 资产链断裂。本集无独立道具时仍输出段落（写"本集无符合标准的独立道具"）。
    5. 头尾安全区
       每次 Seedance 生成的前 0.5 秒和后 0.5 秒为安全区，不放关键内容。开头用于场景建立，结尾用于收住或过渡。

[依赖检测]
    必需（缺失则终止）：
    [1] 用户提供的剧本/梗概/分场文本
        检测：caller 已传入 `episodeText` 或 `novels/{name}/script/ep{N}.md` 存在
        失败话术（一字不改）：
          "缺少本集剧本文本。需要完整剧本/梗概/分场大纲作为输入，请先确认 novels/{name}/script/ 下对应集数文件存在或在调用 packet 中传入 episodeText。"

    [2] 项目根目录 `novels/{name}/`
        检测：目录存在
        失败话术（一字不改）：
          "找不到项目目录 novels/{name}/。需要确认项目名称拼写和项目已初始化。"

    可选（缺失则降级）：
    - `novels/{name}/seedance/assets.json` → 缺失则视为 ep01，所有人物/场景/道具一律标注「新增」
    - `novels/{name}/description` → 缺失则讲戏本中不引用整体画风风格描述，资产清单仍正常输出

[剧情点拆解维度]

    [拆分维度]
        - 情绪转折：基调发生明显变化的位置
        - 时空跳转：场景或时间发生不连续切换的位置
        - 叙事功能转换：从铺垫到冲突、从回忆到现实等功能边界

    [一个剧情点内可包含的镜头组类型]
        - 蒙太奇序列：多个快闪画面组成一个叙事段落（如"十年废材生涯的记忆洪流"）
        - 连续场景：同一叙事目的下的多个镜头
        - 单镜头：简单段落用一个连续镜头讲完

    [时长选择参考]
        | 时长 | 适用场景 |
        |------|---------|
        | 5s   | 单镜头，一个动作或表情变化 |
        | 8s   | 单镜头，一组连贯动作 |
        | 10s  | 多镜头，一段含镜头转换的叙事 |
        | 15s  | 多镜头，完整的多场景叙事（蒙太奇 / 连续切换） |

    [节拍密度规则]
        - 物理动作 1 个 = 1 拍
        - 镜头运动 1 次 = 1 拍
        - 短台词（≤10 字）= 1 拍；超 10 字按 2 拍
        - 同时发生的事合并为 1 拍
        - 单连续镜头总拍数：5s ≤ 2 拍 / 8s ≤ 3 拍 / 10s ≤ 4 拍 / 15s ≤ 6 拍

    [讲戏五维度]
        画面内容 / 人物动作 / 台词或声音 / 镜头感觉 / 光影氛围。
        用自然流畅叙述融合，不分条列举。

    [多镜头段落额外要求]
        - 镜头切换方式（硬切 / 叠化 / 闪白 / 画面碎裂）
        - 子画面节奏（越来越快 / 均匀 / 先慢后快）
        - 整段叙事弧线（如"从希望到绝望的递进"）

[三清单提取规则]

    [人物清单筛选标准]（满足任一）
        - 本集出现在 ≥ 2 个剧情点的人物
        - 本集只出现 1 次但根据已有剧本判断后续集会再次出场的人物
        不列入：本集仅出现 1 次且不再出场的群演 / 一次性配角（在讲戏本中直接描述其外观即可，描述要够具体如"尖脸眯缝眼的白袍学员"而非"一个路人"）。

    [场景清单命名规范]
        - 场景名 = 物理空间名称（如"山门广场""凉亭""下山山道"）
        - 禁止用情节段落命名（如"父亲掏钱段落""叶真独处"）
        - 同一物理空间只列一次，不同情节合并
        - 同一空间不同光影/氛围在 description 中分段描述，不拆为多个场景

    [道具清单筛选标准]（满足任一）
        - 有独立剧情功能（推动剧情、揭示信息、承载情感）
        - 有特写镜头或关键互动
        - 角色标志性随身物品（佩剑、信物、法器）
        - 具有超自然效果（发光、变形、施法载体）
        不列入：场景固定陈设（桌椅、门窗）；一次性背景物；角色服装本身（在人物清单描述）。
        外观描述 30-80 字，必须含形状 / 材质 / 颜色，可选尺寸 / 特殊效果。
        分类取值：兵器 / 法器 / 书卷 / 器物 / 饰品 / 容器 / 其他。

    [素材比对规则]（ep02+ 时执行）
        - 同名同类型未变化 → 复用（附素材 ID）
        - 全新人物/场景/道具 → 新增
        - 同一人物外观变化（换装、老化、受伤）→ 变体（附原素材 ID）
        - 同一场景状态变化（季节、时间、破坏）→ 变体
        - 同一道具状态变化（损毁、激活、变形）→ 变体
        ep01 或 assets.json 不存在时，所有项一律标注「新增」。

[工作流程]
    第 1 步：通读剧本，理清叙事线
        识别核心叙事线、人物关系、情感走向、关键转折点和高潮。
        反向检查：相邻段落是否服务同一叙事目的（合并）/ 单段落是否含两个独立叙事目的（拆分）。

    第 2 步：拆解剧情点
        按 [剧情点拆解维度] 将本集拆为 P01、P02 …。
        每个剧情点确定：人物 / 场景 / 镜头组（单镜头或多镜头 X 组）/ 时长建议（5/8/10/15s）。

    第 3 步：为每个剧情点"讲戏"
        按 [讲戏五维度] 撰写导演阐述（≥ 3-5 句）。多镜头段落补充切换方式 / 子画面节奏 / 整段叙事弧线。
        每段 4-15 秒，遵循 [节拍密度规则] 与头尾安全区。

    第 4 步：提取人物清单
        按 [人物清单筛选标准] 筛选；只记录视觉外观信息（人物名 / 年龄 / 外观关键词）。

    第 5 步：提取场景清单
        按 [场景清单命名规范] 提取；记录场景名 / 时间 / 光线-色调 / 氛围关键词。

    第 6 步：提取道具清单
        按 [道具清单筛选标准] 筛选；记录道具名 / 分类 / 外观描述 / 剧情用途。
        本集无独立道具时仍输出段落，表格中写"本集无符合标准的独立道具"。

    第 7 步：素材比对（ep02+）
        读取 `novels/{name}/seedance/assets.json`，对每行清单按 [素材比对规则] 标注素材状态。
        ep01 或文件不存在 → 全部标「新增」。

    第 8 步：组装并产出
        按 [输出格式] 模板组装完整 markdown，写入 `novels/{name}/seedance/ep{N}/01-director.md`。
        强制三清单完整、每行素材状态字段非空。

[输出风格]
    语态：
    - 导演讲戏式直白叙述。先说画面"是什么"，再说镜头"怎么拍"，再说光"打在哪"。一句一动作或一镜头，连续动作链构成段落节奏。

    反例（明文禁止）：
    × "她表现得很伤心，气氛压抑。"
    ✓ "她背对窗户坐在椅角，右手指节缓缓抠着扶手木纹，肩头一耸一伏。镜头从背影推到右侧脸，停在她睁着却空洞的眼上。冷白荧光灯只照亮半张脸，另一半沉在暗蓝阴影里。"

    × "镜头切来切去展示往事。"
    ✓ "硬切：白袍少年被推搡跌坐尘土。叠化：他独自蜷在角落啃冷馒头。再叠化：他对着空旷山门挥剑空斩。三组子画面节奏越来越慢，最后定格在剑尖映出的孤影。"
