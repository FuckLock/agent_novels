## 剩余问题清单

### 一、项目概览 Tab（overview）

#### BUG-01 [一般] 统计卡片：图标与数字的视觉权重分布与原型图相反

- **严重程度**：🟡 一般（-3分）
- **现状**：图标被包裹在 `w-8 h-8 rounded-lg` 彩色方形背景块中，与数字横向并排（图标左、数字右），标签在下方
- **原型图**：图标无背景色块，直接呈现于卡片左侧；数字为超大字号（约 3xl）顶右对齐；标签"角色数量"等在左下角；整体为图标左上 + 数字右上 + 标签左下的三角分布
- **复现步骤**：访问任意项目概览页，查看四张统计卡片
- **建议**：调整布局为图标在左上（无色块包裹）、数字在右上（字号加大）、标签在左下

#### BUG-02 [建议] 统计卡片：图标外层包裹方形彩色背景，与原型图不符

- **严重程度**：🟢 建议（-1分）
- **现状**：`<div className="w-8 h-8 rounded-lg ... bg-purple-50">` 给图标套了方形背景块
- **原型图**：图标裸呈现，无任何背景色块，视觉更轻盈
- **复现步骤**：查看统计卡片图标区域

#### BUG-04 [一般] 全局设置编辑态：影片比例下拉框缺少默认空选项

- **严重程度**：🟡 一般（-3分）
- **现状**：代码 `page.tsx` 第 432 行直接遍历 `['16:9', '9:16', '1:1']`，无空值占位选项
- **问题**：新项目 `ratio` 字段为空时，下拉框会回落显示第一项"16:9"，误导用户以为已配置
- **复现步骤**：新建项目不填影片比例 → 进入项目概览 → 全局设置 → 点击编辑 → 影片比例下拉框显示"16:9"而非空
- **建议**：在选项最前面加 `<option value="">选择比例</option>`

### 二、小说原文 Tab（chapters）

#### BUG-05 [阻断] 内容摘要列数据错误：显示的是章节名称而非正文内容

- **严重程度**：🔴 阻断（-10分）
- **现状**：代码 `page.tsx` 第 527 行 `{ch.title ? ch.title.substring(0, 50) : '-'}`，内容摘要列截取 `ch.title`（章节名称字段）
- **原型图**：内容摘要列应显示正文内容前若干字，如"炎夏六月，黑水国，齐云宗做为黑水国历史最悠久的修行宗门..."
- **根因**：API `GET /api/projects/[name]` 返回的 chapters 数组仅含 `number/filename/title`，不含正文内容；代码用 `title` 降级替代，逻辑错误
- **复现步骤**：进入有章节数据的项目 → 小说原文 Tab → 观察"内容摘要"列，与"章节名称"列显示相同内容
- **修复方向**：API 返回 chapters 列表时额外提供 `preview` 字段（正文前 80 字），或前端异步请求摘要内容

#### BUG-06 [建议] 新增弹框标题为"新增章节"，原型图标注为"上传小说原文"

- **严重程度**：🟢 建议（-1分）
- **现状**：`page.tsx` 中 `<Modal title="新增章节">`
- **原型图**：弹框标题为"上传小说原文"
- **复现步骤**：点击小说原文 Tab 右上角"+ 新增"按钮

#### BUG-07 [一般] 文件上传仅支持 .txt，原型图标注支持 .txt 和 .docx

- **严重程度**：🟡 一般（-3分）
- **现状**：代码第 761 行 `file.name.endsWith('.txt')`，第 770 行 `input.accept = '.txt'`
- **原型图**：文件上传区提示文字为"支持 .txt, .docx 格式，建议文件大小不超过 10MB"
- **复现步骤**：打开新增弹框 → 拖拽 .docx 文件到上传区 → 文件被忽略，无任何提示

#### BUG-08 [建议] 新增弹框第一步缺少"已解析 N 章节"实时计数

- **严重程度**：🟢 建议（-1分）
- **现状**：字符计数在左侧已实现（`{rawNovelText.length} 字符`），但右侧缺少"已解析 N 章节"实时提示
- **原型图**：文本框底部显示"0 字符"（左）和"已解析 0 章节"（右），两侧对称
- **复现步骤**：打开新增弹框 → 粘贴内容后，右侧无章节解析数量

#### BUG-09 [一般] 原文管理表格缺少"卷"列

- **严重程度**：🟡 一般（-3分）
- **现状**：表格列为：章 / 章节名称 / 内容摘要 / 操作（4列）
- **原型图**：表格列为：章 / 卷 / 章节名称 / 章节内容 / 操作（5列），原型图数据行中"卷"列显示"正文卷"
- **复现步骤**：进入小说原文 Tab 查看表格表头

#### BUG-10 [一般] 编辑章节弹框：章节名称字段不可编辑

- **严重程度**：🟡 一般（-3分）
- **现状**：代码第 849 行 `<input ... disabled ...>`，章节名称字段为只读灰色输入框
- **原型图**：编辑弹框中章节名称字段为可编辑白色输入框（无灰底）
- **复现步骤**：进入有章节数据的项目 → 小说原文 Tab → 点击任意章节"编辑" → 弹框中章节名称呈灰色不可输入
