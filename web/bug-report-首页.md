## 问题详情

### BUG-T01 一般 Sidebar 展开状态底部"收起"按钮缺少文字标签

- **类型**：UI
- **位置**：`web/app/components/Sidebar.tsx` 第 57-64 行
- **描述**：原型图展开状态下，左侧底部展示一个带"收起"文字标签的按钮（左箭头图标 + "收起"文字）。当前代码中该按钮仅渲染一个箭头 SVG 图标，展开时无"收起"文字，与原型图不符。
- **复现步骤**：1. 打开首页；2. 点击展开箭头，侧边栏展开；3. 查看底部左侧按钮区域。
- **期望行为**：展开状态下按钮显示"左箭头图标 + 收起"文字并排。
- **实际行为**：仅显示箭头图标，无"收起"文字。
- **对应原型图**：首页面-左侧展开.png 底部区域

---

### BUG-T02 一般 创建/删除失败使用浏览器原生 alert（延续自 BUG-R05）

- **类型**：交互
- **位置**：`web/app/page.tsx` 第 58 行、第 74 行
- **描述**：创建项目失败时执行 `alert('创建失败')`，删除失败时执行 `alert('删除失败')`，均使用浏览器原生弹框。项目已有统一 Modal 组件，错误提示风格不一致，且原生 alert 阻塞渲染线程，用户体验差。
- **复现步骤**：1. 关闭或模拟 API 服务异常；2. 点击"创建"或"确认删除"按钮；3. 观察弹出的错误提示。
- **期望行为**：使用项目内 Modal 组件或 Toast 方式展示错误信息，与整体 UI 风格一致。
- **实际行为**：浏览器原生灰色 alert 弹框，风格与页面不匹配。
- **此问题从第二轮延续，本轮仍未修复。**

---

### BUG-T03 建议 Sidebar 顶部 Logo 图标形状与原型图存在差异

- **类型**：UI
- **位置**：`web/app/components/Sidebar.tsx` 第 19-21 行
- **描述**：原型图左上角 Logo 为圆形紫色底图上的羽毛/叶子形状图案（品牌特征图形）。当前实现为文件夹形状的 SVG（`M4 8V6a2 2 0 012-2...` 路径为 folder 图形），整体品牌感偏向通用文件管理，与短剧创作平台的视觉定位有差距。
- **期望行为**：使用贴近原型图的圆形品牌图标，如叶/羽毛形状 SVG，或带圆形背景的图标容器。
- **实际行为**：普通文件夹图标，无圆形背景容器。
- **备注**：不影响功能，视觉还原度问题，作为建议项记录。
